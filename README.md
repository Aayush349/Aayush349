## 🚀 Featured Projects

<div align="center">

### 🌾 AgroGuard — AI Crop Disease & Advisory System
*🏆 Hackathon Project · FastAPI · Python · YOLOv8 · React · SQLite · JWT*

> A hybrid AI system combining **Satellite NDVI Analysis** + **Computer Vision** for early crop health monitoring.

- 🤖 **YOLOv8** leaf disease model trained on **380,000+ crop images**
- 🔍 Identifies **150+ pests & diseases** with **~95% precision**
- 📡 **Edge-AI** (TFLite / ONNX) — fully **offline** capable for rural areas
- 🌍 Multilingual crop health reports to guide farmers in prevention

- 📊 React-based **recruiter dashboard** with performance analytics
- ⚡ Low-latency feedback pipeline for seamless candidate experience
